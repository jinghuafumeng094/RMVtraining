# 上车手册

第二阶段（EKF 跟踪与预测）在车上跑、看数、调参。只写操作，不写原理。

配套：`docs/上车前问单-发学长.md`（当天要问的问题）、`docs/答辩-EKF跟踪与预测.md`（设计说明）。

## 1 构建

```bash
cd ~/workplace/rm_autoaim-hxr
cmake -S . -B build -DCMAKE_CXX_FLAGS=-O2
cmake --build build -j"$(nproc)"
ctest --test-dir build --output-on-failure     # 10 个用例全绿
```

产物 `build/rmv_training`。

目录名以 U 盘上的为准：车上两份仓库是 `~/workplace/rm_autoaim-hxr` 与
`~/workplace/rm_autoaim_testrig-hxr`，下文路径都按这个写。宿舍机器上不带 `-hxr`，
`build_*.sh` 与 `run_*.sh` 两种布局都认，`cd` 那类命令要自己换名字。

两条硬约束：

- 不用 `-DCMAKE_BUILD_TYPE=Release`。Release 带 `-DNDEBUG`，`tests/` 里所有裸 `assert` 被编译掉，ctest 假绿。要优化就加 `-DCMAKE_CXX_FLAGS=-O2`。
- 不给 `CMakeLists.txt` 的 `CMAKE_BUILD_TYPE` 补默认值。

依赖：Eigen3、OpenCV 4（core imgproc calib3d objdetect ml imgcodecs）、海康 MVS SDK（默认 `/opt/MVS`，装在别处用 `-DMVS_ROOT=<根目录>`）。MVS 库路径已进 rpath，不用 source 任何 `MVCAM_*`。

Web Debug 默认开。关掉后程序照跑但页面无数据，页面空白先查 `ENABLE_WEB_DEBUG`。

俯视 UI 不在这个仓库里，单独编一次：

```bash
bash ~/workplace/rm_autoaim_testrig-hxr/build_target_topdown_ui.sh
```

产物 `~/workplace/rm_autoaim_testrig-hxr/target_topdown_ui`。它的源列表是手抄的，仓库 `CMakeLists.txt` 加删源文件之后要同步 `build_target_topdown_ui.sh`，否则链接时缺符号。

## 2 运行

```bash
./build/rmv_training <串口设备> <波特率> <相机标定文件> [Web端口]

./build/rmv_training /dev/ttyACM0 115200 config/camera.yaml 8080
```

端口省略即 8080。找串口：

```bash
ls /dev/ttyACM* /dev/ttyUSB*
dmesg | tail -20
```

海康 U3V 相机不在 `/dev/tty*` 也不在 `/dev/video*`。

启动时依次校验，任一失败直接退出：标定文件可读、串口可打开、串口参数可配（115200 8N1）。之后主循环还需要串口持续送来有效帧，否则只回安全帧。

页面：

```bash
xdg-open http://127.0.0.1:8080
curl http://127.0.0.1:8080/health       # OK
```

车在另一台机器上：`ssh -L 8080:127.0.0.1:8080 <用户>@<车>`。

### 2.1 同时看俯视图

```bash
# 车上终端 1：自瞄本体，相机归它
./build/rmv_training /dev/ttyACM0 115200 config/camera.yaml 8080

# 车上终端 2：俯视图，接同一个 Web Debug
cd ~/workplace/rm_autoaim_testrig-hxr
./target_topdown_ui --web --web-port 8080
```

浏览器开 `http://127.0.0.1:8080` 看曲线，俯视窗口看几何，两边是同一个 EKF 状态。

- **车上不能用 `--camera`。** `student/src/HikCamera.cpp:123` 调 `MV_CC_OpenDevice(handle_)` 没给访问模式，走默认独占，`rmv_training` 开着时第二个进程打不开相机。`--web` 不取图、不跑检测，只作为第二个 SSE 客户端读 `/data`。宿舍做检测调试才用 `--camera` 或视频回放。
- 在别的机器上看：先 `ssh -L 8080:127.0.0.1:8080 <用户>@<车>`，本机跑 `./target_topdown_ui --web --web-port 8080`。窗口是本机的，数字来自车上。
- 左上角第一行是连接状态。`web 127.0.0.1:8080` 正常；多一个橙色的 `disconnected` 表示流断了，画面停在最后一帧，那是旧值不是实时值，重连后从环形缓冲那 1.6 秒接着放、画面会跳一下。第二行是 `状态 id d nis`，`nis=--` 表示这一帧没打点。
- `--record 文件名.mp4` 录俯视图，固定 30 Hz；`--scale` 改比例尺，默认 700 px/m；ESC 或 q 退出。关掉俯视图不影响 `rmv_training`。

**没有相机时不要跑 rmv_training。** 取流连续失败 4 帧操作线程退出、程序结束；而相机自身要连续 5 次取图失败才重开，每次最长等 1 秒，重开逻辑在这条路径上走不到，USB 抖一下程序就没了。宿舍看页面用回放：

```bash
cd ~/workplace/rm_autoaim_testrig-hxr
bash build_web_debug_replay.sh
./web_debug_replay          # 浏览器开 http://127.0.0.1:8080
./target_topdown_ui --web   # 另一个终端，不用相机也能看俯视图
```

页面三个坑：

1. 历史只有约 1.6 秒。缓冲 10000 条样本，满帧 38 条、165 fps，约 263 帧铺满。先开浏览器再让车动。
2. 不要刷新页面。刷新后只从环形缓冲那 1.6 秒重新发。
3. 程序退出服务即断。

相机参数由程序每次开盘写死：`ExposureTime 5000 us`、`Gain 0 dB`、`ExposureAuto/GainAuto/BalanceWhiteAuto` 全 Off。用 MVS 客户端或 `params.py` 调过相机之后，必须跑 `set_baseline.py` 写回并读回核对，否则那段时间的图是坏的。

敌方颜色由串口 `status` 决定：5 时敌方红，其余敌方蓝。不是本程序的参数。

## 3 上车调试步骤

按顺序做，前一步没过不做下一步。参数全在 `student/include/ArmorEkf.hpp` 的 `Config`，是编译期默认值，改完重编（本机约 4 秒）。

### 第 0 步 核对读数，先别调

车停住、云台俯仰归零，等 `ekf_state = 1`。

- 看 `ekf_z_m` 与板心高度的差。差两三公分不用追，里面混着外参 z（51.5 mm）与安装误差，是常数偏置。
- 能核的是变化量：原地转、俯仰不动，换板瞬间 `ekf_z_m` 的台阶应等于两块板真实高差；哨兵相对两块等高，台阶应为 0。
- `plate_height_m` 默认全零不影响瞄准，只影响上报的 `center_z_m`。
- 半径是常量，不是待调参数。`initial_radius_m`、`min_radius_m`、`max_radius_m` 三处必须是同一个数，默认 0.303（靶车 Video_1 两板心弦长 0.428 m 算出）。换成别的车时先量旋转中心到板心，三处一起改；`ekf_radius_1_m` 与 `ekf_radius_2_m` 读数应恒等于这个值，不等就是没重编。

### 第 1 步 调 R（观测噪声）

```text
lateral_noise_scale   0.002     lateral_noise_base_m  0.005
depth_noise_scale     0.010     depth_noise_base_m    0.010
```

`sigma = scale * 距离 + base`。标尺是 `ekf_nis_mean`：2 到 4 之间就算匹配。

先横向两个一起倍率化，不够再动深度。NIS 均值 > 4 就乘 1.5 到 2 倍；< 2 就乘 0.5 到 0.7。

### 第 2 步 调 Q 平移项

`accel_noise_m_s2`，默认 6.0。

动作：手在镜头前挡 0.2 秒再拿开，看 `ekf_state` 几帧回 1、`ekf_streak` 从负回升多快。调大恢复快但稳态抖，调小相反。取恢复够快的拐点。

### 第 3 步 调 Q 转动项

`angular_accel_noise_rad_s2`，默认 12.0。

让车原地转。已知两条：慢转（ω > 0）进不了 Stable 是调参问题，进 Stable 的门槛约 ω ≈ 0.8 rad/s；完全不转进不了 Stable 是几何问题，调它没用。

这一项与 `stable_yaw_std_rad` 是同一件事的两端，调它时别同时放宽那个门。

### 第 4 步 最后动 Stable 三闸与开火容差

```text
stable_center_std_m      0.10    stable_frames        15
stable_radius_std_m      0.05    recover_frames       10
stable_yaw_std_rad       0.10    stable_hold_misses    3

fire_yaw_tolerance_rad   0.02    fire_pitch_tolerance_rad 0.02
fire_spin_tolerance_rad_s 1.0
```

前三步没调好之前不放宽这三道门，否则 `ekf_state` 变绿而状态没收敛。

`fire_pitch_tolerance_rad` 比的是 `target_pitch`（含下坠补偿的弹道发射角）与当前云台绝对仰角之差，即指令到位没有。

## 4 怎么调试

### 4.1 页面 38 个键

EKF 26 条 + 图像 12 条。每张图只画一个键，不能叠加；右上角 CSV 导出单键历史。

| 组 | 键 | 判读 |
|---|---|---|
| 检测 | `armor_count` `detection_id` `detection_confidence` | 跟踪时常态 1 块，两块只在换板瞬间。`detection_id = 0` 表示不是 1 到 8 的贴纸，整条不画 |
| 单帧位姿 | `pnp_reprojection_error` `pnp_distance_m` `pnp_yaw_rad` `pnp_pitch_rad` `target_x_px` `target_y_px` | 重投影正常 0.7 到 0.8 px，超过 5 px 被拒。这是唯一直接可见观测值的一组，EKF 出问题先看它 |
| 运行 | `camera_fps` `empty_frame` `process_time_ms` | 帧率约 165 |
| EKF 状态 | `ekf_x_m` `ekf_y_m` `ekf_z_m` `ekf_vx_m_s` `ekf_vy_m_s` `ekf_vz_m_s` `ekf_yaw_rad` `ekf_yaw_rate_rad_s` `ekf_radius_1_m` `ekf_radius_2_m` | 世界系 x 前 y 左 z 上，原点在云台旋转轴。半径按槽位奇偶分开 |
| 状态机 | `ekf_state` `ekf_streak` `ekf_aim_index` `ekf_rejected_count` `ekf_nis_mean` `ekf_best_nis` | `ekf_state` 0 无目标 / 1 Stable / 2 Unstable，它就是通信字段 `crc`。`ekf_streak` 正为连续命中、负为连续丢失。`ekf_best_nis` 见 4.2 |
| 输出 | `target_id` `target_yaw` `target_pitch` `target_distance_m` | `target_yaw` 绝对方位角；`target_pitch` 是含下坠补偿的发射仰角。`crc != 1` 时 `fire_allowed` 恒假 |
| 派生角 | `ekf_plate_me_angle_rad` `ekf_slot_phase_rad` `ekf_plate0_parallax_rad` | 由已估状态拼出，不回流滤波器，见 4.3 |
| 参照 | `gimbal_yaw` `armor_orientation_yaw` `ekf_meas_yaw_rate_rad_s` | 只用相机原始量，不经过滤波器，见 4.4 |

### 4.2 读 NIS

`ekf_nis_mean` 是最近 5 次被接受的更新的 NIS 均值，理论值 3。

- 均值 2 到 4：R 量级对。
- 远大于 3：R 填小了，真观测被当成异常批量拒掉。
- 远小于 3：R 填大了，观测权重低，收敛慢、跟踪滞后。

被拒的帧不进均值，所以必须和 `ekf_rejected_count` 一起看。

`ekf_best_nis` 补的正是这个洞：它取本帧那条观测的 NIS，**取值在闸门之前**，被拒的帧也留数。

- 大于 `nis_gate` 11.34：这一帧是被统计闸挡的。远大于，比如上百，说明滤波器状态已经飞了，先看 `ekf_x_m` `ekf_vx_m_s`。
- 不打点：本帧没有一条观测走到槽位比较，被跳变闸、重投影闸或重复板判据挡在前面。
- 正常而 `ekf_nis_mean` 不动：这一帧没有更新被接受。

`ekf_state` 卡在 2 有两条路：协方差三道门没过（要等，不调参）或 NIS 门没过（`ArmorEkf.cpp` 里均值门槛 8.0，要动 R 或 Q）。NIS 是唯一能区分的量。

离线回放无噪声，NIS 在 1e-4 量级，只能证明这个数活着。均值该等于 3 只能上车做。

### 4.3 派生角：一屏分开三路状态

三个角只记 0 号槽位，另外三块板差 90 度固定相位。车体匀速自转时波形可事先算出。

| 键 | 波形 | 周期 | 对不上说明 |
|---|---|---|---|
| `ekf_plate_me_angle_rad` | 三角波 0 到 pi | `2 pi / omega` | 斜坡速率不等于 `ekf_yaw_rate_rad_s` 则 yaw 没收敛；同一条各段速率差得多则看 `ekf_x_m` `ekf_y_m` |
| `ekf_slot_phase_rad` | 三角波 0 到 pi/4 | `pi / (2 omega)` | 只由 `ekf_yaw_rad` 决定。这条干净而上面那条毛，问题在中心；两条一起毛，问题在 yaw |
| `ekf_plate0_parallax_rad` | 绕 0 的正弦 | `2 pi / omega` | 幅值约 `asin(radius_1_m / 距离)`，幅值偏大是半径估大；整条偏离 0 是中心估偏 |

第一条周期正好是第二条的四倍，与任何参数无关，是最硬的判据。理论形状和刻度看 `docs/img/派生角波形.png`，本机回放实测看 `docs/img/派生角三例.png`。

### 4.4 参照角速度：判跟不上还是模型有偏

```text
theta_world = armor_orientation_yaw + gimbal_yaw
omega_car   = -d(theta_world)/dt
```

`ekf_meas_yaw_rate_rad_s` 与 `ekf_yaw_rate_rad_s` 贴在一起说明滤波器跟得上相机；分叉说明它更信模型。分叉两种方向相反：跟不上是过程噪声给小了（`angular_accel_noise_rad_s2`、`accel_noise_m_s2`），模型有偏是观测噪声给错了（R 的四个系数）。先看分不分叉再决定拧哪边。

`armor_orientation_yaw` 原样输出不过闸，换板那一帧 90 度跳变是正常的。`ekf_meas_yaw_rate_rad_s` 的 45 度跳变闸挡得住换板，挡不住平板 PnP 双解翻转的约 1.2 度跳变。

### 4.5 波形定方向，NIS 定哪一头

页面上没有真值线，波形只能判「太紧还是太松」，判不了绝对准不准。同一个抖动，Q 调大和 R 调小都让增益变大，形状一样，靠 NIS 分开：

| 形状 | R 那头 | Q 那头 |
|---|---|---|
| 跟得太紧，毛刺穿到输出 | R 小，NIS 高 | Q 大，NIS 低 |
| 跟得太松，换向时落后 | R 大，NIS 低 | Q 小，NIS 高 |

`pnp_yaw_rad` / `pnp_pitch_rad` 是相对当前云台的角度，`target_yaw` / `target_pitch` 是绝对角，比形状可以，别比绝对值。

## 5 现象对照

| 现象 | 先确认 | 改哪个，往哪改 |
|---|---|---|
| `ekf_rejected_count` 一直涨，`ekf_streak` 频繁归零 | `ekf_nis_mean` 均值 | NIS > 4：R 填小，横向两个先乘 1.5 到 2，再动深度。NIS 正常：看下面两行 |
| 停在 `ekf_state = 2`，观测没被拒、`ekf_streak` 为正 | 慢转还是完全不转 | 慢转：`angular_accel_noise_rad_s2` 调小。完全不转：几何问题，调它没用 |
| 同上且卡在位置那一路 | `ekf_x_m` `ekf_y_m` 还在飘 | `accel_noise_m_s2` 调小（6.0 改 3.0） |
| 收敛慢 | 慢的是位置还是 yaw | 位置：`accel_noise_m_s2` 调大。yaw：`angular_accel_noise_rad_s2` 调大 |
| 稳住了但读数抖 | 抖的是位置还是 yaw | 位置：`accel_noise_m_s2` 调小。yaw：`angular_accel_noise_rad_s2` 调小 |
| 挡住 0.2 秒就掉出 Stable | 多久变 2 | `stable_hold_misses` 调大（3 改 5） |
| 观测回来了回 Stable 很慢 | `ekf_streak` 从负爬到正要多久 | 爬得快：`recover_frames` 调小（10 改 5）；爬得慢：观测在被拒，回第一行 |
| 丢一次直接回 0 | 丢失是否真超过 1.5 秒 | 真超过是正确定义，不动 `reset_timeout_s`；没超过是观测在被拒 |
| 换板瞬间 `target_yaw` 跳 | 跳幅 vs `aim_switch_margin_rad` | `aim_switch_margin_rad` 调大（5 度改 8 度）。先确认不是观测被拒 |
| `ekf_z_m` 换板跳台阶 | 是否等于两块板真实高差 | 正常，不用改 |
| 云台对齐但 `fire_allowed` 不给 | `target_yaw`、`target_pitch`、`ekf_yaw_rate_rad_s` 各差多少 | 方位差：`fire_yaw_tolerance_rad`。仰角差：`fire_pitch_tolerance_rad`。自转没停：`fire_spin_tolerance_rad_s` |
| `pnp_distance_m` 乱跳 | `pnp_reprojection_error` | 不动 EKF，回位姿解算 |
| `armor_count` 老为 0 | `detection_id` `detection_confidence` | 不动 EKF，回检测或颜色阈值 |

进 Stable 的三道协方差门读的是 `P` 的对角线，页面上看不见，现场只能靠物理现象反推。要判得干脆就补两三个 `P` 对角线键，落点同 2026-10-17 加的 NIS 键。

三条纪律：

1. 一次只动一个参数，否则分不清是谁的功劳。
2. 先插电，不插电主频掉一半，跨轮比绝对值没有意义。
3. 单次异常值不许升级成规律。

# 上车前问单（2026-10-15）

大作业第二阶段要上车跑 EKF。下面第 1 组三条只有电控侧能答，答错了代码不报错、只会静默跑偏；第 2 组四条顺带问，答不答都能开工。

回的时候一句话就行，不确定的写"不确定"，我们按当前默认值做，并在报告里标明哪些是默认值、哪些是实测值。

**2026-10-16 更新**：原 1.6（`target_pitch` 要不要含弹道下坠补偿）已按"补偿是算法组做"落实，代码改成输出弹道发射仰角、开火门同步改，本条已从下面移除。

## 第 1 组：必须先落定

### 1.3 `crc` 的 0 / 1 / 2

**问**：`crc = 0 / 1 / 2` 是不是"无目标 / 预测稳定 / 有目标未稳定"？与电控侧的理解一致吗？"稳定"的判据由谁定？

**当前默认**：按任务书与 `轨迹预测说明.md` 实现 —— `0` 无目标、`1` 稳定且唯一允许开火、`2` 有目标未稳定。"稳定"是这边定的：连续命中 15 帧、位置协方差达标、最近 5 次更新的 NIS 均值达标。

**答错的后果**：若电控侧期望别的划分，或者期望更早进 `1`，开火时机就不对。这一条是评分红线，希望明确一句。

### 1.5 `gimbal.yaw` / `gimbal.pitch` 的符号

**问**：`yaw` 取正是右转还是左转？`pitch` 取正是抬头还是低头？

**当前默认**：`yaw` 右正、`pitch` 上正。

**答错的后果**：滤波器跟得住、指令方向反 180 度，而重投影误差、深度这些自检闸门全都看不出来，属于静默错。改法只有一处，代价很小，但必须问。

### 1.7 `message.yaw` 是机械角还是场地角

**问**：电控下发的 `yaw` 是"云台相对车体底盘"的机械角，还是已经和 IMU 融合的"相对场地"的角？

**当前默认**：不区分，两种口径下公式都自洽，只影响怎么解释。

**答错的后果**：数值不会错，错的是解释。答辩被问"你这个 yaw 相对谁"答不上来是概念错；另外也决定一帧多车该在哪一层筛。

## 第 2 组：顺带问

### 2.5 车上那台相机内参的标定材料

**问**：`config/camera.yaml` 现在这组（fx 1782.6 / fy 1784.3 / cx 749.4 / cy 574.7，畸变 `[-0.0357, -0.1533, 0, 0, 1.1905]`）是哪台相机、用什么工具、采了多少张图标的？

**为什么问**：提交物里要一份"完整标定材料"，包含标定方法、采样过程和误差验证。这组数是队里给的，我们手上只有数值本身。如果队里标过，把工具和采图张数给一句就够；有平均重投影误差的话一并给。

### 2.3 弹速

**问**：实际弹速多少？

**当前默认**：用仓库默认 24 m/s（`armor/include/BulletModel.hpp`，`Kf = 0.08`，`g = 9.81`）。

**答错的后果**：弹道飞行时间对初速敏感，远距离提前量直接受影响。要是只能现场用测速仪量，说一声。

### 2.6 `message.bias` 的单位

**问**：`bias` 的单位是秒吗？代表哪一段延迟？

**当前默认**：按秒用，进 `预测时长 = 处理延迟 + bias + 弹道飞行时间`。

**答错的后果**：单位差一千倍会让预测时长直接顶到上限，提前量全错。

### 2.7b 一帧里可能有几辆敌车

**问**：一帧画面里通常有几辆敌车？有可能两辆及以上同框吗？

**为什么问**：现在的流程把一帧里所有同色装甲板全部喂给同一个"单目标四板"模型，EKF 之前没有目标筛选。若经常两辆同框，八块板会一起进一个模型，要先定筛选放在哪一层；若基本只有一辆，这条可以直接跳过。

## 第 3 组：上车当天我们自己量，不用答

写在这里只是说明我们清楚这几项还空着，不是要你回答：

- 相邻两块装甲板的**高差**：高度表现在按四块共面填。已确认它只影响 `center_z_m` 上报量、不影响瞄准（高度和中心高度进的是同一个方程），所以不专门量；换板时 `ekf_z_m` 的台阶顺带就能读出来
- 装甲板到车体旋转中心的**半径**：现在按 0.25 m 假设
- 车的**机动能力量级**：决定过程噪声大小，要在车上扫参数
- `7` 号板上的贴纸是不是 `7`：现场看一眼
- 一句范围问题：本轮要不要跟踪**前哨站**，不要的话就按标准步兵四块板做
